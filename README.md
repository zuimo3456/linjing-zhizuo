# 邻镜智作研究原型

这是独立重构版本。先读《先读这个_重构决策与执行路线.md》。原申报文件、旧原型和旧素材保留原处。

## 打开与体验

当前电脑服务地址为 http://127.0.0.1:4180 。如果服务已关闭，双击“启动邻镜智作.cmd”，保留运行窗口，随后在浏览器打开此地址。

第一次在其他电脑运行：需要Windows、Python 3.12或uv、FFmpeg和ffprobe、Microsoft YaHei字体及中文Windows系统语音。start.ps1会创建独立环境并安装requirements.txt；当前电脑已建好环境。Linux和macOS语音路径尚未实现，不宣称跨平台即开即用。

1. 点击“体验模拟案例”。四段原创插画测试片会载入，并明确显示“模拟案例”。
2. 点击“生成可检查的方案”。检查门头、商品和环境顺序，以及每句事实引用。
3. 删掉地址，或取消某个镜头确认，再生成，查看阻止生成和补拍提示。
4. 恢复样本，确认方案并生成视频。等待页面结果，播放，下载MP4、运行报告和证据包。
5. 点击“研究与验证”，查看程序用例和真实实验的区别；人工复核记录可导出CSV。

新项目应点击“开始真实项目”，上传获授权的视频，填写事实和来源，检查抽帧并确认镜头标签，再编排。上传真实素材会退出模拟项目，避免混入模拟事实。导入项目JSON不包含原始视频；跨电脑使用时仍需准备原素材。

## 已实现与限制

已实现：多文件上传、镜头边界和亮度清晰度检测、人工确认标签、模型候选导入、事实确认、三类目标、最大覆盖镜头分配、受限文案组合、缺失提示、离线配音字幕、预览下载、项目保存、抽帧标注包、运行证据及合成约束回归。

待完成：真实模型接口联调、可靠自动语义理解、原声与画外音自动分流、精确字级字幕、背景音乐闪避、可编辑封面和多画幅、手机实机与跨电脑验收、真实商户试用及论文实验。当前只有720×1280画外音路径。字幕按段测量旁白时长，段内换行时间按字数近似；声音较长会停留末帧并记录时长。

默认全部本地运行，无付费API调用。视觉API适配器是未联调的可选能力，不会因为电脑已有其他密钥而自动调用。它只在显式设置LINJING_VISION_API_URL、LINJING_VISION_API_KEY、LINJING_VISION_MODEL并执行带--send-frames的命令时，发送选定抽帧到配置的供应商；不发送店铺事实卡。调用前应核对授权和预算。

服务仅监听127.0.0.1，适用于本机开发，不是公开生产服务。不要直接改成公网监听。素材在data/，默认不上传云端、不入Git，目前没有自动清理机制；人工备份与删除应核对项目后操作。当前任务队列只存内存，服务重启会丢失任务状态，已生成文件仍在data/。

## 开发入口

| 文件 | 作用 |
|---|---|
| planner.py | 输入检查、角色与镜头分配、事实引用、方案校验 |
| media.py | 镜头检测、抽帧、离线配音、字幕与视频渲染 |
| server.py | 本地接口、异步任务、受限文件访问和视频Range请求 |
| static/ | 网页界面与操作流程 |
| vision_adapter.py | 标注包、候选标签校验及可选视觉接口 |
| demo.py | 明确标为模拟数据的插画测试片 |
| run_benchmark.py | 运行约束回归，输出evidence/constraint-results.json |
| docs/ | 调研、研究协议、导师沟通稿、采集和答辩材料 |

在项目目录运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 run_benchmark.py
.\.venv\Scripts\python.exe -X utf8 server.py
```

requirements-lock.txt记录本机实际解析版本，复现时优先用uv安装该文件；requirements.txt记录直接依赖。不要把.venv、data、密钥和商户授权材料提交到普通代码仓库。

## 如何理解核心算法

以到店目标为例，有门头、商品、环境三个角色；每个镜头可以支持一个或多个角色。相同镜头只分配一次，优先填满三个角色，再提高质量与可用时长。用三个二进制位表示角色是否已覆盖，共8种状态，依次考虑各镜头即可完成分配。这里的状态转移与C++动态规划练习相通。

例子：镜头A同时可作门头和商品，质量高；镜头B只能作门头，镜头C只能作环境。逐个贪心先把A用作门头会缺商品；全局分配选择B作门头、A作商品、C作环境。tests/test_invariants.py有此用例。算法不能检验标签是否看错，因此需要独立评价模型标签与人工确认成本。
