# 饭店首页与拍摄引导

后续修订：2026年11月3日的镜头要求已升级为v2，本文件保留首版接线记录。最新素材需求见《餐饮平台研究与素材需求修订_2026-11-03.md》和《餐饮18组完整拍摄清单_v2_2026-11-03.md》。

日期：2026年11月2日。状态：已实现，浏览器与旧资源入口兼容复核通过；用户尚未验收。

## 使用

打开 http://127.0.0.1:4193/ 。首页依次选择饭店类型、宣传目标，填写店名与具体菜品／套餐。右侧摘要随输入更新；信息完整后进入相应拍摄清单。

- 饭店类型：家常炒菜、火锅、烧烤、粉面、早餐快餐、小吃。
- 宣传目标：推荐一道菜、推广一个套餐、介绍我的饭店。
- 门店介绍以饭店为宣传对象，填写的菜品用于搭配展示。
- 三类目标分别进入 `#shoot/signature`、`#shoot/offer`、`#shoot/restaurant`。
- 每份清单包含四个镜头任务，以及建议时长、具体拍法和检查重点。
- 通过“我的工作台”或“已有素材”入口可以直接继续原有项目。

问候跟随浏览器本地时间，5–10时早上好、11–17时中午好，其他时段晚上好。每分钟、切回页面或回到首页时更新。

## 与原工作台连接

拍摄清单的“素材准备好了，进入工作台”将店名、菜品和目标带入新草稿，保留 `creative_brief` 供显示及导出／导入使用。三类目标映射现有 `attract`、`promo`、`visit`，后端剪辑与配音行为不变。

所有新填写事实都未确认，来源为空，仍需用户核实。已有项目包含素材或事实时，用户可以返回或取消，也可以先实际导出备份再开始。同一份创作再次进入时保留工作台内容。

首页选择存在当前标签页的sessionStorage，刷新清单后仍可恢复；工作台仍通过原“保存项目／导出项目”保存，首页不自动覆盖服务器保存项目。

## 复现与验证

在项目目录使用现有环境启动独立预览：

```powershell
.\.venv\Scripts\python.exe -X utf8 -c "from http.server import ThreadingHTTPServer; from server import Handler; ThreadingHTTPServer(('127.0.0.1',4193),Handler).serve_forever()"
```

使用已有独立浏览器测试环境，无需下载新浏览器：

```powershell
.\data\browser-test-env\Scripts\python.exe -X utf8 verify_restaurant_home_browser.py
```
