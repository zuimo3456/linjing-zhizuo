# 开源活泼女声接入与验证

日期：2026年11月2日。用户要求把现有配音改为活泼女声，采用已训练好的开源模型。本轮采用Qwen官方Qwen3-TTS-12Hz-1.7B-CustomVoice，预置Vivian中文女声；模型与代码均为Apache-2.0。无需训练、语音克隆、付费接口或上传商户素材。

## 为什么选这个模型

官方将Vivian描述为明亮的年轻中文女声，1.7B CustomVoice支持自然语言情绪控制，符合“活泼”的目标。0.6B虽然更小，官方功能表不列其情绪指令控制，未作为等价替换。Kokoro 1.1中文模型更轻，适合CPU部署，但本轮优先利用已有8GB RTX4060验证可控制语气的方案。此选择表示功能适配，最终是否自然、有吸引力仍需用户试听。

## 现在怎么用

本轮女声预览：`http://127.0.0.1:4191/`。原4180服务在本轮期间被其他工作重新启动，本轮检查发现PID变化后未停止该服务，以4191独立运行新版。常规`启动邻镜智作.cmd`仍启动4180，需旧服务关闭后再启动才会加载新代码。

进入网页，恢复/导入项目或体验模拟案例，确认素材和事实，然后重新生成方案，再生成视频。旧方案提示配音已更换，素材和事实保留；旧MP4仍是原声音，需重新生成。正文中的价格和活动条件仍来自确认事实，没有为适配配音而省略条件。

试听文件及18.8秒模拟技术样片位于`交付/开源活泼女声/`。文件包括普通宣传、价格日期、地址条件三段WAV，以及MP4、运行报告和可恢复项目。均为技术模拟，不对应真实商户。用户应核对数字、日期、英文房号及整体听感。

## 接入行为与验证边界

`qwen_voice_worker.py`在隔离环境内加载固定模型，以Vivian和固定轻快指令推理，HF离线模式且禁用遥测；原文不发送到远端。使用按文本固定的随机种子，短句分别生成，拒绝空音频、非有限值、异常音量或达到生成长度上限；不静默切回Windows旧声。运行库导入会提示可选SoX/flash-attn缺失，实测当前SDPA推理路径成功，不需要安装这两项。

`audio.py`保留逐短句测时、间隔、静音裁切、限幅、最多1.18倍适配速度、字幕跟随实测段时长。生成缓存含模型版本、音色、指令和参数指纹，不会复用Huihui音频；相同短句跨方案复用。空闲两分钟释放模型进程和显存，磁盘缓存保留。`pipeline.py`对旧配音指纹方案要求重编排，服务恢复保留事实和镜头确认；报告记录实际模型、指令、版本和测时。

程序检查120/120（原111+新增9）通过，网页脚本语法检查通过。实际生成三段音频，分别约6.234、9.640、5.248秒；普通宣传首次整段生成37.964秒（含加载和处理），其他新句也慢于语音播放时长，不能称实时。重复读取缓存约0.001秒以内。12个实际生成短句的模型推理峰值显存最高4185MiB，系统/浏览器额外占用不在此数内。实际API重新编排、校验、渲染模拟促销项目成功：`684b444bdaa3406d9a8c3fe51736f74d`，18.821333秒，720×1280含音轨；最长旁白组16秒，实际仅约1.01528倍速度，保留全部活动条件。旧声方案确实返回400并要求重新测时。完整性核对见`evidence/voice-2026-11-02/verification.json`。

本轮通过接口验证实际编码文件，未把它宣称为正常浏览器完整播放、浏览器下载、真人听感或商户验收。尝试独立Edge窗口时被最小化/用户输入打断，已停止继续操作该窗口；预览链接已交给应用打开，用户可直接检查。没有声称模型绝不会错读或漏读，特别是金额、日期和房号仍应试听。模型虽带情绪指令，也不保证每句听起来同样活泼。

## 复现

在本目录安装`安装开源女声.ps1`；常规启动脚本不再依赖Windows Huihui。独立验证服务启动命令（另开已有终端运行）：

```powershell
.\.venv\Scripts\python.exe -u -X utf8 -c "from http.server import ThreadingHTTPServer; from server import Handler; ThreadingHTTPServer(('127.0.0.1',4191),Handler).serve_forever()"
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests
.\.venv\Scripts\python.exe -X utf8 verify_neural_voice.py --port 4191
```

最后一项使用有期限的2026年11月促销模拟事实，跨日期重跑时需更新测试副本的有效期，不能把过期拦截算成配音缺陷。不会写用户主保存项目。`synthesize.ps1`仅保留作历史实现参考，主路径已不调用。模型安装需要联网；安装并校验完成后，实际文字合成无需联网。
