# 网站部署与更新

2026年11月2日部署，11月3日复核。部署方式：GitHub Pages在线预览；不迁移本地视频生成服务。

公开网址：https://zuimo3456.github.io/linjing-zhizuo/ 。无需安装环境或登录GitHub。

## 同学能在线查看什么

首页分时问候、六种饭店筛选、三类宣传目标、具体店名和菜品填写、实时摘要、对应拍摄清单、工作台表单与页面草稿导出均可交互。在线版有明确提示，不接收视频，不运行AI素材分析、配音或视频生成；不会尝试连接访问者电脑或原开发电脑的本地API。

预览草稿只在页面内编辑，可以导出JSON保存；首页选择保存在当前标签页的sessionStorage。原开发电脑的项目、原视频、模型、生成结果不会随部署发布。完整成片功能仍按协作开发指南在本地运行。

## 自动更新

`.github/workflows/pages.yml`在main分支的 `static/**`、构建脚本或工作流更新时自动运行，也支持GitHub Actions手动启动。发布前检查JS语法，构建预览文件，然后使用GitHub官方Pages动作上传和发布；仅部署main。

团队流程：各自分支开发→提交Pull Request→审核合入main→等待“Publish website preview”工作流成功→刷新在线网址。文档修改不会触发不必要的页面部署。

工作流：https://github.com/zuimo3456/linjing-zhizuo/actions/workflows/pages.yml

部署状态成功前，不把提交成功当作网站已更新；如失败，在工作流内查看失败步骤。

## 构建与本地检查

```powershell
python scripts/build_web_preview.py
python -m http.server 4195 --bind 127.0.0.1 --directory .
```

打开 http://127.0.0.1:4195/web-preview/ 。普通本地版仍运行 `python -X utf8 server.py`，两种模式共享同一套前端源码。

构建只复制 `index.html`、`app.js`、`style.css`，并生成 `preview-config.js`、`version.json` 和 `.nojekyll`。入口资源使用相对地址，可在仓库子路径下加载。输出目录已有未知文件时会拒绝构建，避免夹带本地资料。

仅公开构建入口注入 `LINJING_PREVIEW_MODE=true`，本地HTML没有此标志。在线模式跳过本地初始化请求，停用需要后端的按钮，草稿导出直接在浏览器完成；不会用假接口伪装生成成功。

`version.json`记录实际部署的源代码提交，便于核对网页版本。此文件由构建时的GITHUB_SHA生成，不含账户凭据。
