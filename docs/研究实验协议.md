# 邻镜智作真实素材实验协议草案

版本1，2026年10月23日。当前真实商户数和真实样本数均为0。以下是准备执行的实验设计，不是实验结果。

## 研究单位与样本

先导阶段建议4家商户、每家3个任务，共12个任务，用于发现标注歧义、计时错误和明显失败。先导样本不用于挑选最终测试效果。

正式阶段建议12家商户，覆盖餐饮、零售、生活服务至少3类，每家约5个任务，共约60个输入任务。8家用于开发与提示调试，4家作为锁定测试商户；不训练模型时称“开发集”，不称训练集。按商户隔离，同一店铺的换镜头、同一素材的重复导出不得跨集合。

该规模是可行性建议，不是论文统计功效保证。若只能完成6家，应明确为小样本试点，缩小外推范围。原申报要求至少3类场景、30条样例需要独立核对，不可用本项目的程序用例数量替代。

每个任务保存：匿名商户ID、场景、目标、原始素材哈希、授权记录索引、确认事实与来源、镜头标签、缺失信息、人工作业时间、模型版本、输入输出、随机参数、机器环境、首稿及修订稿。授权材料单独保管，不放入公开仓库。公开数据集须取得单独许可并清理人脸、声音和位置等内容。

## 比较方法

| 方法 | 定义 | 当前实现状态 |
|---|---|---|
| A 素材顺序 | 使用相同可用镜头和文案，按输入顺序排列 | 已实现；属于较弱、透明的顺序基线 |
| B 直接多模态模型 | 固定相同输入与模型，直接生成结构化剪辑方案 | 待接入并固定供应商；不能用坏提示故意削弱 |
| C 证据约束方法 | 候选标签与事实引用、全局分配、校验、缺失提示 | 本地规则及人工确认部分已实现；云端标签适配未联调 |
| D 人工简易剪辑 | 同素材、相近输出时长，记录实际人工时间 | 待制作，不能把精修商业片与机器首稿混比 |

模型输入帧预算、输出时长、分辨率、音轨策略和字幕样式保持一致。B和C使用相同基础模型，保存提示词、模型名、参数与使用量。既报告完全自动的候选结果，也报告经确认的结果；不能只给C提供人工真值标签，却称其全自动优于B。

当前A与C的区别主要是排序，不足以单独支撑论文。正式研究必须包含B及合理的规则/贪心强基线。MoneyPrinterTurbo、FunClip可做工程参照，但输入任务不同，只有对齐其适用任务后才可进行公平效果比较。

## 消融

固定测试集，分别移除：事实约束、全局分配、质量分、缺失素材反馈。一次只移除一个模块。

事实约束消融可以先评估文字和剪辑方案，不把有错营销文案发布。缺失反馈应另设有缺口任务，比较“系统指出补拍需求”和“只报失败”，并计入补拍及重传时间。仅用完整素材无法检验补拍模块。

模型候选标签与人工核对标签分别实验，以估计语义理解错误和编排错误。所有处理共享同一测试素材，不能为某方法换更好素材。

## 主要指标

事实错误：由独立人工评审按原子陈述拆分，记录每条是否有确认事实支持、是否与材料矛盾。报告无依据陈述率及任务级错误率。程序ID检查不能替代这项语义标注。

目标信息覆盖：所需内容是否同时具备正确文案与对应画面。地址出现在字幕但没有门头，不自动算位置表达完整。

拒绝与成功：总任务数固定，报告生成成功、拒绝、系统错误三类比例。同步画出不同阈值下的错误率与生成覆盖率；全部拒绝不能被解释为“零幻觉最优”。

人工成本：从开始操作到达到可接受版本的总人工秒数，包括标签确认、事实修正、补拍、上传和修改。另报告纯机器时间。保存首稿与终稿，统计改了什么。

用户效果：自然度、音画对应、信息清晰度分别1—5分，写具体问题时间点。真实商户发布意愿单独统计，不能由学生观看意愿代替。愿意发布不等于已发布，更不等于增加营业额。

资源成本：实际API账单或用量×当时价格，另列计算、存储等成本和未计量项；记录每次失败和重试，不只展示最低成本成功例。

## 评审与统计

至少两位独立标注者先标同一批样本，记录原始分歧，再讨论形成参考标签。不要只保存协商后的“完全一致”结果。报告适合类别数据的一致性指标，并核对低一致性的定义。

观看评价隐藏方法名称，随机呈现顺序，采用相同播放设备与音量设置。商户本人评价与独立观看者评价分别报告。研究表格中的人工评分只是采集工具，不会自动证明盲评或代表性。

以商户为聚类单位报告配对差值和置信区间，必要时采用按商户重采样的bootstrap；不要把同店的多个导出当成许多独立商户。测试商户过少时侧重描述性结果和局限，避免过度依赖显著性。

在打开锁定测试集之前冻结方法、阈值、主要指标和失败计数规则。若修改，应另记版本，旧结果保留。模型主观打分只能辅助，不能既由同一模型生成又只由它自评。

## 通过与停止条件

工程验收与研究结论分开。工程验收检查真实上传、表单、任务反馈、播放、下载、手机兼容和异常恢复；研究验收检查强基线、数据隔离、事实与音画人工评价、失败案例和复现记录。

本轮的合成约束回归测试，只证明所列输入满足/不满足程序规则；不证明真实语义理解、字幕逐字准确、自然度、手机可用性、商户满意度或3分钟/3元承诺。

如果C减少错误但确认时间过高，报告该取舍并尝试减少确认项；若B已足够好，报告适用边界；若缺失提示没有节省总时间，不再把它当作既成创新。没有正结果也要保留失败数据。
