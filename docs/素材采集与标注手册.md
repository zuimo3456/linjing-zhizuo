# 邻镜智作首批素材采集与标注

先找一家能反复沟通的小店，不要求第一天就覆盖所有店型。获得店方同意后再拍，记录素材是否允许用于内部测试、答辩展示和公开研究；三种用途分别确认。不要默认一次口头同意等于允许公开整个数据集。

## 一次到店要带回什么

每类稳定竖拍5—8秒：门头及可辨识路线、主推商品、制作或服务过程、店内环境。补拍一段较差但仍可用的镜头，用于质量筛选实验。避开顾客正脸与谈话；如需店员出镜，应另行确认。

建立匿名商户编号，如SHOP01，原片文件名示例SHOP01_product_01.mp4。保留未经剪辑的原文件，另记录哈希。不要使用平台下载视频冒充团队实拍。

事实卡记录店名、商品、地址、优惠的完整条件、适用时间及各自来源；某项不提供就留空，不能为让系统通过而补造。店主确认的陈述也可能存在误解，需要留存核对依据。不要为了演示而擅自添加“全市第一”“最低价”等说法。

先用同一批素材制作15—25秒人工参考片，逐段写下用了哪个原片的哪个时间范围、为什么选它、对应哪句话。这个参考用于判断拍摄表达是否可行，不当作自动系统结果。

## 标签规则

storefront：可支持门店外观或路线表达。product：主体商品可见且可辨。process：实际制作或服务动作可见。interior：消费或服务环境可见。person：人物是画面主体。other：不确定或不属前述类别。

不能因为文件名含“商品”就确认product；不能因为看到桌子就自动认定它属于目标店铺。模型置信度是模型输出，不是经过校准的真实准确概率。描述仅写可见内容，不推测价格、门店身份、口味或营业情况。

两人先独立标同一批镜头，原始标注分别保存，再记录协商结论；把歧义写回手册。人物与商品同时出现时可多标签，当前页面主要提供单标签修改，多标签可由候选JSON输入并人工核对。

## 现场访谈的五个问题

1. 最近一次想发短视频是什么时候？最后发了没有？可以看一次实际过程吗？
2. 哪一步最耗时，最近一条片实际用了多久？
3. 你最担心系统把哪些信息说错？谁能确认这些信息？
4. 看这一版，你愿意直接发、修改后发，还是不发？具体改哪里？
5. 如果下周再做一条，你是否愿意再次提供素材并试用？

不要先问“这个AI工具是不是很有用”。不要把对方出于礼貌说“挺好”写成付费意愿。当前不承诺带来客流，也不代替商户发布。
