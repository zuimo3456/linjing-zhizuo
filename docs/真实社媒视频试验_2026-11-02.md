## 实际观察

1. **切镜与用途识别仍需明显人工介入。** 初始5个片段被分析为344个镜头：116个完成模型候选分析、228个被跳过；完成分析的116个中仅62个给出非弃权用途候选。肠粉85秒被切138段，109段跳过。这里“完成分析”不等于分类正确，62也不是准确率。饺子吃播动作被多次当作制作过程；咖啡装饰/海报展示也出现制作候选。助手看抽帧后纠正选中用途，通过原有确认接口签名，不让模型自己确认。

2. **横屏放进竖屏后主体很小。** 当前保留完整画面而不裁切，16:9源画面在9:16画布中仅占约31.6%高度；上下深色空白很大。新字幕在下方留白区域，原片字幕和水印仍在，两个字幕来源同时出现，旧字幕可能在讲原博主的另一句话，也保留了原片当年的价格，不能当作当前报价。新增字幕还出现句号或末字单独换行。视频可播不等于已经适合发布。

3. **文案与结构偏机械。** 实际生成仍是“带你看看商品 / 这是制作过程 / 这是店内环境 / 感兴趣可以先收藏”。没有自动提炼卖点、消除探店口播或形成新的门店叙事，原声和背景音乐被移除。早餐店环境段实际展示店内备餐台，和制作段视觉相近。咖啡样片介绍的是咖啡豆，没有冒充成手冲成品展示。

4. **缺镜头时拦截有用，但固定结构限制了覆盖面。** 饺子和多店vlog都有商品画面，却缺可确认的制作镜头，环境短片也放不下完整旁白，因此未成片；没有把吃东西、拆包装、搅拌自己饮料当成商家制作。混入风险片段确认被拒后没有放宽或绕过。
