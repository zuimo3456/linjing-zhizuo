# 邻镜智作开源与论文调研

核查日期2026年10月23日。优先查作者、维护者和官方仓库；本轮不是系统综述或专利查新。工程参考、安装运行、实际集成和实验胜出是四种不同状态。

## 相关研究

[Text-to-Edit](https://arxiv.org/abs/2501.05884)与[作者项目页](https://text2edit.github.io/)已经讨论多模态模型理解素材、控制广告视频编辑及输出映射。因此不能把“多模态理解后生成结构化剪辑方案”本身写成你们首创。该工作与真实素材编排最相关，应优先精读方法和评价部分。

[The Anatomy of Video Editing](https://arxiv.org/abs/2207.09812)关注素材组织与辅助镜头组装，说明视频编辑研究不仅是改画面、加特效。它的电影镜头域与小店手机素材域不同，可参考任务设计，不能直接视为你们的商户需求证据。

[Qwen3-VL官方仓库](https://github.com/QwenLM/Qwen3-VL)提供多图、视频理解等接入示例，可作为候选素材理解模块。模型能接受视频，不代表它能够可靠识别某店商品或支持实际商业事实。

本轮检索还发现多个以画面变换为主的视频编辑基准。它们与“从多个真实素材中选择、排序”的任务并不等价，不能仅因为名称含Video Editing就套用指标。正式论文前仍需扩展最新相关工作、阅读原文并与导师确认研究缺口。

## 开源工程取舍

| 工程 | 已核实用途 | 本项目决定与当前状态 |
|---|---|---|
| [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo) | 主题或关键词驱动脚本、素材、字幕与合成工作流 | 下载并查看视频合成源文件和许可；参考工程分层，未安装、未运行整套工程，没有把它当创新 |
| [FunClip](https://github.com/modelscope/FunClip) | 语音识别、文本片段选择、时间戳剪辑 | 下载并查看videoclipper.py，关注时间戳清洗与字幕路径；未安装运行，不用于无原声商品素材的默认编排 |
| [PySceneDetect](https://github.com/Breakthrough/PySceneDetect) | 镜头切换检测 | 新环境已安装0.7.1并实际集成运行。固定版本用于复现，不声称它是最新版本 |
| [OpenCV](https://github.com/opencv/opencv) | 画面读取、清晰度及亮度指标 | 已安装4.11.0.86并实际集成；低层指标无法替代语义理解 |
| [faster-whisper](https://github.com/SYSTRAN/faster-whisper) | 基于CTranslate2的语音转写 | 查看官方说明与许可；本次未接入新版本，原声保留与精确字幕作为下一阶段 |
| [Qwen3-VL](https://github.com/QwenLM/Qwen3-VL) | 多模态素材理解 | 查看官方示例与许可；未下载本地大模型，避免在无硬件效果证据时增加环境负担 |

当前没有直接复制上述两套成片工程的实现进入本地服务。新服务实际依赖FFmpeg、OpenCV、PySceneDetect、Pillow和Windows系统语音。没有安装一堆互不相关插件，也未创建外部账户。

## 可复核的源码证据

evidence/upstream-lock.json 保存了5个仓库的提交SHA、核查时间、文件网址、文件大小和SHA256。evidence/open-source-snapshots/ 保存原README、许可及选定源文件；该目录默认不进Git。只下载供查阅，没有执行上游文件。

MoneyPrinterTurbo的video.py可查看字幕处理、片段组合和FFmpeg相关路径；FunClip的videoclipper.py可查看时间戳规范化和文本到剪辑区间路径。团队要借鉴时应说明具体模块和测试结果，不能只写“参考GitHub前辈代码”。

## 许可与归属

本轮下载的MoneyPrinterTurbo、FunClip与faster-whisper许可文件标为MIT，PySceneDetect为BSD文本，Qwen3-VL仓库许可文件为Apache 2.0。实际模型权重、外部素材、字体和在线服务可能有各自条款；仓库许可不自动覆盖这些资源。源文件的准确版本见锁定记录，保留下载的原始许可文本。

Windows语音是本机已有能力，语音品质和使用场景仍需按实际环境检验。本轮没有引入在线Edge TTS作为默认路径，未作商用授权判断。FFmpeg构建的具体许可取决于构建选项，分发安装包前应保存ffmpeg -version和-buildconf结果。

建议先以私有团队仓库存放自写代码与研究记录，暂不发布原始商户素材和模型密钥。后续发布或软著材料应清楚列明第三方依赖，不能把开源基础能力写成全部由团队自主研发。
