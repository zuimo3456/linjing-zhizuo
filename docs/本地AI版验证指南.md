# 本地AI版验证指南

日期：2026年10月29日。当前是可试用的本地技术版本，尚未经过真实商户或用户最终验收。

## 先体验一次

1. 打开 http://127.0.0.1:4180/ 。服务关闭时双击项目里的“启动邻镜智作.cmd”。
2. 点击“体验模拟案例”。先试“到店消费”或“引流关注”。
3. 点击“本地 AI 分析素材”。模型用三张不同时间抽帧比较用途。插画常被判为“不确定”，这是真实推理结果；不应为了演示把它改成高分。
4. 展开“查看本段视频与抽帧”，核对实际画面。在下拉框选择用途，再勾选“我已查看并确认标签”。商品镜头另勾选“画面商品确实是：手冲咖啡”。
5. 点击“生成可检查的方案”，检查每段用途、文案、事实引用。点“确认方案并生成视频”，等待并播放。
6. 观察切换画面时旁白是否对应、字幕是否对应短句、文字是否被遮挡、人声是否自然。请把不满意的时间点直接告诉Codex。

也可以跳过AI按钮，完全手工确认素材走固定结构基准。这条路径用于比较AI到底节省了多少标注时间，不能把手工标签当成模型效果。

## 用自己的素材验证

先准备获授权的门头、商品、环境各一段，稳定竖拍，每段约6—8秒；先用一个商品、一个目标。也可添加制作过程，测试引流目标。

点击“开始真实项目”，上传。填写真实店名、商品、地址和来源，再勾选确认。AI不读取招牌来替你确认地址、优惠或价格；这些必须人工提供。模型分析后请看视频，确认标签和商品对应。

缺素材时，补拍提示是合理结果。不能把无关画面改成“商品”只为通过检查；程序无法验证人为作出的虚假确认。

## 建议故意试错

| 操作 | 应出现的结果 |
|---|---|
| 取消地址确认，目标为到店 | 提示确认地址，不能生成 |
| 修改商品名 | 原商品对应确认失效，要重新核对画面 |
| AI结果暂不判断且未人工确认 | 提示确认或补拍，不能自动使用 |
| 用很短镜头承载很长旁白 | 说明需要的语音时长，拒绝靠长停帧凑时长 |
| 模型文件缺失或损坏 | 明确失败，可继续用手工标签；不伪造AI结果 |

当前模拟案例的完整优惠文案约需7.8秒，而商品片段只有6秒，因此促销生成会被时长检查拒绝。不要删掉优惠使用条件来通过；先验证到店/引流流程。当前结构每段最多8秒，特别长的条款尚需后续拆分结构。

## 怎样评价这一步是否值得继续

用相同素材比较“手工标签”和“AI候选后确认”两次流程，记录总耗时、标签纠正数、事实错误、商品配错、首稿修改和观看评价。模型等待时间之外，还要计入人看视频和修正的时间。

本轮通过了47项程序回归、两条模拟音画链路和网页实际播放；这些都不能证明真实视频识别准确率、比赛创新性或商户愿意发布。先做一个获授权店铺的小试验，再决定是否需要更大的视觉模型。

短句字幕按实际生成音频测时，不是逐字字幕。素材、抽帧和推理在本机处理；模型安装需要下载权重，生成时不调用云端模型。还没有背景音乐或原声精剪，这轮不以扩功能代替核心效果验证。
